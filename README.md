# ব্যক্তিগত প্রেমচুক্তি — বাংলা ওয়েবসাইট

একটি scroll-based, responsive romantic treaty website. মূল চুক্তিপত্রটি একটি কাগজের A4 পাতায় দেখানো হয় এবং PDF-এও শুধু সেই পাতাটিই export করা হয়।

## ফাইল কাঠামো

```text
forbidden-treaty/
├── index.html
├── css/
│   ├── style.css
│   └── dark.css   ← ডার্ক থিম (পেপার, রঙ, গ্রেইন)
├── js/
│   └── app.js
└── README.md
```

## চালানো

1. ফোল্ডারটি Extract করে VS Code-এ খুলুন।
2. `index.html` Live Server দিয়ে খুলুন, অথবা সরাসরি ব্রাউজারে চালান।
3. ঐচ্ছিক ধারাগুলি নির্বাচন করুন; কাগজের দলিলে সেগুলি সঙ্গে সঙ্গে দেখা যাবে।
4. নাম ও তারিখ পূরণ করুন, দ্বিতীয় পক্ষের স্বাক্ষর আঁকুন এবং সম্মতির checkbox দিন।
5. “সিলমোহর সম্পন্ন করুন” চাপার পর “স্বাক্ষরিত PDF ডাউনলোড” চাপুন।

## PDF সম্পর্কে

PDF তৈরি করতে html2canvas ও jsPDF CDN থেকে এবং বাংলা ফন্ট Google Fonts থেকে লোড হয়, তাই ইন্টারনেট সংযোগ প্রয়োজন। দুইটি CDN ঠিকানা ধারাবাহিকভাবে চেষ্টা করা হয়। PDF তৈরি হয় কেবল `contractPaper` নামের কাগজের অংশ থেকে; সেটিকে নির্দিষ্ট 794 × 1123 ক্যানভাসে রেন্ডার করে একক A4 পাতায় বসানো হয়। ওয়েবসাইটের অন্য section PDF-এ যায় না এবং auto-pagination করা হয় না।

যদি উভয় CDN-ই লোড না হয়, “প্রিন্ট হইতে PDF সংরক্ষণ” বিকল্পটি দেখা যাবে। সেটি নতুন উইন্ডোতে শুধু দলিলের কাগজ খুলবে। ব্রাউজারের Print dialog-এ Destination হিসেবে **Save as PDF** নির্বাচন করুন, Paper size **A4**, Margins **None** এবং Scale **Default/Fit** রাখুন। নতুন উইন্ডো খুলতে ব্রাউজার অনুমতি চাইলে অনুমতি দিন।

## নোট

এটি ব্যক্তিগত হাস্যরসাত্মক স্মারক, আইনগত চুক্তি নয়। কোনো বাক্য বা স্বাক্ষর শারীরিক স্পর্শের স্থায়ী অনুমতি বোঝায় না।
